# Folk Dance Player — Plan 6: Canva Slides Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each dance can carry its Canva slide, and the projector shows it beside the program while the dance is up. The organizer:
- adds a Canva deck once, by its public view link, and links a dance to a slide by its number (or a pasted slide link)
- sees the slide on the projector, top right: the saved image at once, then the live Canva page once its controls have faded
- keeps working offline: every linked slide's image is saved in the background, and "Refresh slides" re-reads the decks and saves the images again

**Architecture:**
- **Main process:** owns Canva.
  - **Reading decks** (`src/main/canva/`): `canva-url` normalizes share links; `deck-parser` reads a deck's title and ordered slides (page ID and title) from its public view page; `canva-client` fetches pages (through an injected `Fetcher`); `decks` is the repository (`canva_decks`, `dance_prefs` slide columns, `slide_cache`), resolving a dance's page ID to its position *now*.
  - **`CanvaService`** adds decks, links slides, and refreshes (at startup when online, and on "Refresh slides").
  - **Saving images:** `CaptureQueue` captures linked slides one at a time through a `SlideCapturer`; `createSlideCapturer` drives one off-screen Canva page (load, mouse nudge, wait for the fade, capture), reusing it within a deck. Images are saved under the app data folder and served to the renderers as `fdp-media://slide/<deck>/<page>`.
  - **Live view:** `LiveSlide` keeps one `WebContentsView` over the projector window's slide box (`slideBox`), hidden until Canva's controls have faded. `createProjectorFeed` puts the middle dance's slide in the snapshot and tells `LiveSlide` which slide to show.
  - All of these take injected pieces, so they're unit-tested; `electron-canva.ts` is the thin Electron glue.
- **Renderer:** the projector page draws the with-slide layout and the saved image in the same box main lays the live view over. The song editor gets a slide field per dance (with the link dialog); the Music page gets "Refresh slides" with the captures' progress and a "Canva links need checking" notice.

**Tech Stack:** As Plans 1–5. No new dependencies, and no schema change (migration 001 already has `canva_decks`, `slide_cache` and the `dance_prefs` slide columns).

**Spec:** `docs/superpowers/specs/2026-10-13-folk-dance-player-electron-design.md`. Read §6.3 (linking a slide, Refresh slides), §8.2 (the with-slide layout), §8.3 (Canva slides) and §9. Task 10 updates the spec with this plan's decisions.

This is plan 6 of 7. Plans 1–5 are merged. **Not in this plan:**
- a Slide column or ⚠ in the library table (the editor shows the slide and any warning)
- re-checking the live view when the network comes back mid-session (the saved image stays until the next slide change)
- packaging: Plan 7

**Decisions made with the user while planning** (recorded in the spec by Task 10):
- **Saved image, then live:** the projector shows the saved image at once and switches to the live Canva view only once its controls have faded (about 11 s after loading; 1.5 s for another slide of the same deck). The live view never shows Canva's controls, a blank page or "Loading…".
- **The slide area is top right,** as the spec's mockup: the top half of the screen, previously played on the left, the slide on the right two-thirds (16:9, fitted). Now playing and Up next stay below at full width.
- **Capturing:** at startup when online, only linked slides with no saved image are captured; "Refresh slides" re-captures every linked slide.

**Verified by spike while planning** (each is built into a task):
- **The deck page:** the public view page of a real 42-slide deck carries its title (`og:title`) and the slide objects `{"A?":"i","Z":{…},"a":"<pageId>","B":"<title>"}` in order. (Task 1; the fixture is a trimmed copy of that page's format)
- **Short links:** `canva.link/…` answers 301 to `…/edit?ui=<base64 {"D":{"T":{"A":"<pageId>"}}}>`. (Tasks 1, 3)
- **Off-screen capture works:** a hidden off-screen `BrowserWindow` loads the view page in 3–5 s; after a mouse pass and about 12 s the controls have faded and `capturePage()` is clean. (Tasks 4, 7)
- **Same-deck slide changes:** loading the same view URL with another `#N` switches the slide in the page in milliseconds, without reloading, and the controls stay hidden. (Tasks 4, 5)

## Review Focus

These are the five failure modes most likely to bite an organizer during an event. Each has a test in the task that owns it.

1. **Canva changes its page format** (it's undocumented): decks must keep their last slide list and saved images, and the control window must say "Canva links need checking"; nothing changes on the projector. Task 2: "no slides, or none we knew, means the format changed…"; Task 3: "a changed page format is reported…"; Task 9: "\"Canva links need checking\" while a deck's format changed".
2. **No internet at the event:** the saved image shows, the live view never appears, and startup doesn't try to refresh. Task 3: "at startup: nothing offline…"; Task 5: "offline, or when the page fails to load, the saved image stays".
3. **Canva's controls or a half-loaded page on the projector:** the live view stays hidden until the fade, a slide change hides it again, and a slide switched away from before its fade never appears. Task 5: the live-slide tests.
4. **A slide deleted or moved in Canva:** a moved slide follows its page ID; a deleted one is flagged in the editor, keeps its image on the projector, and is never loaded live (its position is gone). Task 2: "a slide inserted in Canva moves the others…" and "a slide deleted in Canva…"; Task 7: "a slide no longer in its deck shows its saved image, never live"; Task 9: "warns when the slide is gone from its deck…".
5. **Canva pages reaching the app:** navigating off Canva, opening windows, or a second copy of the app opening the same library. Task 6: "the Canva views may navigate within Canva only…"; Task 7 wires the session, sandboxing and the single-instance lock.

```ts
// Canva links (spec §8.3). Any share link of a deck is normalized to its plain public view link;
// a page link from Canva's share menu (canva.link → …/edit?ui=…) names one slide's page ID.

export interface DeckLink {
  viewUrl: string // https://www.canva.com/design/<designId>/<token>/view
  designId: string
}

const DESIGN_PATH = /^\/design\/([A-Za-z0-9_-]+)\/([A-Za-z0-9_-]+)\/(view|watch|edit)\/?$/

function parse(input: string): URL | null {
  try {
    const url = new URL(input.trim())
    return url.protocol === 'https:' && /^(www\.)?canva\.com$/.test(url.hostname) ? url : null
  } catch {
    return null
  }
}

// A deck's public view link, without ?embed, other query parameters or a #slide fragment.
// Editor links need a Canva login, so they aren't accepted as decks.
export function normalizeDeckUrl(input: string): DeckLink | null {
  const url = parse(input)
  const match = url && DESIGN_PATH.exec(url.pathname)
  if (!match || match[3] === 'edit') return null
  return {
    viewUrl: `https://www.canva.com/design/${match[1]}/${match[2]}/view`,
    designId: match[1]
  }
}

export const isShortLink = (input: string): boolean => {
  try {
    return new URL(input.trim()).hostname === 'canva.link'
  } catch {
    return false
  }
}

// The design and page a Canva page link points to: …/edit?ui=<base64 of {"D":{"T":{"A":"<pageId>"}}}>
// (where a canva.link short link redirects).
export function pageFromEditLink(input: string): { designId: string; pageId: string } | null {
  const url = parse(input)
  const match = url && DESIGN_PATH.exec(url.pathname)
  const ui = url?.searchParams.get('ui')
  if (!match || !ui) return null
  try {
    const data = JSON.parse(Buffer.from(ui, 'base64').toString('utf8')) as {
      D?: { T?: { A?: unknown } }
    }
    const pageId = data.D?.T?.A
    return typeof pageId === 'string' && /^[A-Za-z0-9_-]{8,40}$/.test(pageId)
      ? { designId: match[1], pageId }
      : null
  } catch {
    return null
  }
}

// The view link opened at a slide position (1-based).
export const viewAt = (viewUrl: string, position: number): string => `${viewUrl}#${position}`
```

Create `src/main/canva/deck-parser.ts`:

```ts
import type { CanvaPage } from '@shared/canva'

// Canva's public view page embeds the design as minified data. Each slide is an object that
// starts {"A?":"i","Z":{…},"a":"<pageId>" and, when the slide is named, continues ,"B":"<title>".
// The format is undocumented, so the caller self-checks the result (spec §8.3).
const SLIDE = /\{"A\?":"i","Z":\{[^{}]*\},"a":"([A-Za-z0-9_-]{8,40})"(?:,"B":"((?:[^"\\]|\\.)*)")?/g

const ENTITIES: Record<string, string> = { amp: '&', lt: '<', gt: '>', quot: '"', apos: "'" }

function decodeEntities(text: string): string {
  return text.replace(/&(#\d+|#x[0-9a-f]+|[a-z]+);/gi, (whole, code: string) => {
    if (code[0] !== '#') return ENTITIES[code.toLowerCase()] ?? whole
    const n =
      code[1] === 'x' || code[1] === 'X' ? parseInt(code.slice(2), 16) : Number(code.slice(1))
    return Number.isFinite(n) ? String.fromCodePoint(n) : whole
  })
}

function decodeJsonString(raw: string): string {
  try {
    return JSON.parse(`"${raw}"`) as string
  } catch {
    return raw
  }
}

export interface ParsedDeck {
  title: string | null
  pages: CanvaPage[] // in order; empty means the format wasn't recognized
}

// The presentation's title (from og:title, else <title>) and its ordered slides.
export function parseDeckPage(html: string): ParsedDeck {
  const og = /<meta[^>]+property="og:title"[^>]+content="([^"]*)"/i.exec(html)
  const titleTag = /<title>([^<]*)<\/title>/i.exec(html)
  const rawTitle = og?.[1] ?? titleTag?.[1] ?? null
  const title = rawTitle === null ? null : decodeEntities(rawTitle).trim() || null
  const pages: CanvaPage[] = []
  const seen = new Set<string>()
  for (const match of html.matchAll(SLIDE)) {
    if (seen.has(match[1])) continue
    seen.add(match[1])
    const name = match[2] === undefined ? '' : decodeJsonString(match[2]).trim()
    pages.push({ id: match[1], title: name || null })
  }
  return { title, pages }
}
```

```ts
// Canva slides reach the projector by deck and page, so a renderer never names a path (spec §9).
export const MEDIA_SCHEME = 'fdp-media'

export const mediaUrl = (fileId: number): string => `${MEDIA_SCHEME}://file/${fileId}`

export function parseMediaUrl(url: string): number | null {
  const match = /^fdp-media:\/\/file\/(\d+)\/?$/.exec(url)
  return match ? Number(match[1]) : null

  const match = /^fdp-media:\/\/slide\/(\d+)\/([A-Za-z0-9_-]+)\/?(?:\?.*)?$/.exec(url)
  return match ? { deckId: Number(match[1]), pageId: match[2] } : null
```

```ts
import { createReadStream } from 'node:fs'
import { stat } from 'node:fs/promises'
import { extname } from 'node:path'
import { Readable } from 'node:stream'

const MIME: Record<string, string> = {
  '.mp3': 'audio/mpeg',
  '.m4a': 'audio/mp4',
  '.aac': 'audio/aac',
  '.wav': 'audio/wav',
  '.flac': 'audio/flac',
  '.ogg': 'audio/ogg',
  '.oga': 'audio/ogg',
  '.opus': 'audio/ogg',
  '.png': 'image/png'
}

// One byte range from a Range header ("bytes=a-b", "bytes=a-" or "bytes=-n"), clamped to the
// file; null when the header asks for something the file doesn't have.
export function parseRange(header: string, size: number): { start: number; end: number } | null {
  const match = /^bytes=(\d*)-(\d*)$/.exec(header.trim())
  if (!match || (match[1] === '' && match[2] === '')) return null
  if (match[1] === '') {
    const suffix = Number(match[2])
    if (suffix === 0) return null
    return { start: Math.max(0, size - suffix), end: size - 1 }
  }
  const start = Number(match[1])
  const end = match[2] === '' ? size - 1 : Math.min(Number(match[2]), size - 1)
  return start < size && start <= end ? { start, end } : null
}

// Serves an audio file to <audio> (or a saved slide image to the projector), honoring Range requests so seeking works (spec §9).
export async function mediaResponse(path: string | null, range: string | null): Promise<Response> {
  if (!path) return new Response('Not found', { status: 404 })
  let size: number
  try {
    const info = await stat(path)
    if (!info.isFile()) return new Response('Not found', { status: 404 })
    size = info.size
  } catch {
    return new Response('Not found', { status: 404 })
  }
  const type = MIME[extname(path).toLowerCase()] ?? 'application/octet-stream'
  const body = (start: number, end: number) =>
    Readable.toWeb(createReadStream(path, { start, end })) as ReadableStream
  if (!range) {
    return new Response(size === 0 ? null : body(0, size - 1), {
      status: 200,
      headers: { 'Content-Type': type, 'Content-Length': String(size), 'Accept-Ranges': 'bytes' }
    })
  }
  const r = parseRange(range, size)
  if (!r) {
    return new Response(null, { status: 416, headers: { 'Content-Range': `bytes */${size}` } })
  }
  return new Response(body(r.start, r.end), {
    status: 206,
    headers: {
      'Content-Type': type,
      'Content-Length': String(r.end - r.start + 1),
      'Content-Range': `bytes ${r.start}-${r.end}/${size}`,
      'Accept-Ranges': 'bytes'
    }
  })
}
```

```ts
import type { DatabaseSync } from 'node:sqlite'
import { FORMAT_CHANGED } from '@shared/canva'
import { slideUrl } from '@shared/media'

export { FORMAT_CHANGED }
import type { CanvaDeck, CanvaPage, DanceSlide } from '@shared/canva'
import { inTransaction } from '../db/transaction'
import type { DeckLink } from './canva-url'
import type { ParsedDeck } from './deck-parser'

const NOW = "strftime('%Y-%m-%dT%H:%M:%fZ', 'now')"

// A rule a deck or slide action broke; the message is shown in the control window.
export class CanvaError extends Error {
  constructor(message: string) {
    super(message)
    this.name = 'CanvaError'
  }
}

interface DeckRow {
  id: number
  viewUrl: string
  designId: string
  title: string | null
  pages: string
  syncedAt: string | null
  lastError: string | null
}

const DECK_SQL = `SELECT id, view_url AS viewUrl, design_id AS designId, title, pages,
  synced_at AS syncedAt, last_error AS lastError FROM canva_decks`

const pagesOf = (row: DeckRow): CanvaPage[] => JSON.parse(row.pages) as CanvaPage[]

const toDeck = (row: DeckRow): CanvaDeck => ({
  id: row.id,
  viewUrl: row.viewUrl,
  designId: row.designId,
  title: row.title,
  pageCount: pagesOf(row).length,
  syncedAt: row.syncedAt,
  lastError: row.lastError
})

function deckRow(db: DatabaseSync, deckId: number): DeckRow {
  const row = db.prepare(`${DECK_SQL} WHERE id = ?`).get(deckId) as DeckRow | undefined
  if (!row) throw new CanvaError('That deck is no longer in the app.')
  return row
}

// Decks by title, for the editor's dropdown.
export function listDecks(db: DatabaseSync): CanvaDeck[] {
  return (
    db.prepare(`${DECK_SQL} ORDER BY title COLLATE NOCASE, id`).all() as unknown as DeckRow[]
  ).map(toDeck)
}

export function deckPages(db: DatabaseSync, deckId: number): CanvaPage[] {
  return pagesOf(deckRow(db, deckId))
}

export const deckByDesign = (db: DatabaseSync, designId: string): CanvaDeck | null => {
  const row = db.prepare(`${DECK_SQL} WHERE design_id = ?`).get(designId) as DeckRow | undefined
  return row ? toDeck(row) : null
}

// Adds a deck (or updates the one with the same view link). A page we can't read isn't saved.
export function saveDeck(db: DatabaseSync, link: DeckLink, parsed: ParsedDeck): number {
  if (parsed.pages.length === 0) {
    throw new CanvaError(
      "Couldn't read the slides of this deck. Is it shared as a public view link?"
    )
  }
  db.prepare(
    `INSERT INTO canva_decks (view_url, design_id, title, pages, synced_at, last_error)
     VALUES (?, ?, ?, ?, ${NOW}, NULL)
     ON CONFLICT (view_url) DO UPDATE SET title = excluded.title, pages = excluded.pages,
       synced_at = excluded.synced_at, last_error = NULL`
  ).run(link.viewUrl, link.designId, parsed.title, JSON.stringify(parsed.pages))
  return (
    db.prepare('SELECT id FROM canva_decks WHERE view_url = ?').get(link.viewUrl) as { id: number }
  ).id
}

// A refreshed copy of the deck's view page (spec §8.3). The format is undocumented, so it
// self-checks: no slides at all, or none of the slides we knew, means the format changed. Then the
// last known list stays in use (so do saved images) and the deck is flagged. A failed fetch keeps
// everything as it was. Otherwise the new list is saved.
export function applyRefresh(
  db: DatabaseSync,
  deckId: number,
  result: { parsed: ParsedDeck } | { error: string }
): 'ok' | 'format-changed' | 'unreachable' {
  const old = pagesOf(deckRow(db, deckId))
  const flag = db.prepare('UPDATE canva_decks SET last_error = ? WHERE id = ?')
  if ('error' in result) {
    flag.run(result.error, deckId)
    return 'unreachable'
  }
  const { pages, title } = result.parsed
  const known = new Set(pages.map((p) => p.id))
  if (pages.length === 0 || (old.length > 0 && !old.some((p) => known.has(p.id)))) {
    flag.run(FORMAT_CHANGED, deckId)
    return 'format-changed'
  }
  db.prepare(
    `UPDATE canva_decks SET title = COALESCE(?, title), pages = ?, synced_at = ${NOW},
       last_error = NULL WHERE id = ?`
  ).run(title, JSON.stringify(pages), deckId)
  return 'ok'
}

function storeSlide(
  db: DatabaseSync,
  danceId: number,
  deckId: number,
  pageId: string,
  index: number | null
) {
  db.prepare(
    `INSERT INTO dance_prefs (dance_id, canva_deck_id, canva_page_id, canva_page_index)
     VALUES (?, ?, ?, ?)
     ON CONFLICT (dance_id) DO UPDATE SET canva_deck_id = excluded.canva_deck_id,
       canva_page_id = excluded.canva_page_id, canva_page_index = excluded.canva_page_index`
  ).run(danceId, deckId, pageId, index)
}

// Links slide number `position` (1-based, as Canva shows it) to a dance; stores its page ID.
export function setDanceSlide(
  db: DatabaseSync,
  danceId: number,
  deckId: number,
  position: number
): string {
  return inTransaction(db, () => {
    const pages = deckPages(db, deckId)
    const page = Number.isInteger(position) ? pages[position - 1] : undefined
    if (!page) throw new CanvaError(`This deck has slides 1 to ${pages.length}.`)
    storeSlide(db, danceId, deckId, page.id, position)
    return page.id
  })
}

// Links a slide by its page ID (from a page link), in the deck with that design.
export function setDanceSlideByPage(
  db: DatabaseSync,
  danceId: number,
  designId: string,
  pageId: string
): void {
  inTransaction(db, () => {
    const deck = deckByDesign(db, designId)
    if (!deck) throw new CanvaError('Add this deck first, with its public view link.')
    const index = deckPages(db, deck.id).findIndex((p) => p.id === pageId)
    if (index < 0) throw new CanvaError("That slide isn't in the deck. Try Refresh slides.")
    storeSlide(db, danceId, deck.id, pageId, index + 1)
  })
}

export function clearDanceSlide(db: DatabaseSync, danceId: number): void {
  db.prepare(
    `UPDATE dance_prefs SET canva_deck_id = NULL, canva_page_id = NULL, canva_page_index = NULL
     WHERE dance_id = ?`
  ).run(danceId)
}

// A dance's slide, with its position now (spec §8.3: looked up by page ID, so inserting or moving
// slides in Canva doesn't break the link). Null when the dance has none.
export function getDanceSlide(db: DatabaseSync, danceId: number): DanceSlide | null {
  const row = db
    .prepare(
      `SELECT dp.canva_deck_id AS deckId, dp.canva_page_id AS pageId, sc.image_path AS imagePath,
         sc.captured_at AS capturedAt, sc.last_error AS captureError
       FROM dance_prefs dp
       LEFT JOIN slide_cache sc ON sc.deck_id = dp.canva_deck_id AND sc.page_id = dp.canva_page_id
       WHERE dp.dance_id = ? AND dp.canva_deck_id IS NOT NULL AND dp.canva_page_id IS NOT NULL`
    )
    .get(danceId) as
    | {
        deckId: number
        pageId: string
        imagePath: string | null
        capturedAt: string | null
        captureError: string | null
      }
    | undefined
  if (!row) return null
  const deck = deckRow(db, row.deckId)
  const pages = pagesOf(deck)
  const index = pages.findIndex((p) => p.id === row.pageId)
  return {
    deckId: deck.id,
    deckTitle: deck.title,
    viewUrl: deck.viewUrl,
    pageId: row.pageId,
    title: index < 0 ? null : pages[index].title,
    position: index < 0 ? null : index + 1,
    status: index < 0 ? 'missing' : 'ok',
    imageUrl: row.imagePath === null ? null : slideUrl(deck.id, row.pageId, row.capturedAt ?? ''),
    captureError: row.captureError
  }
}

export interface CaptureTarget {
  deckId: number
  pageId: string
  viewUrl: string
  position: number
}

// The linked slides to capture: all of them, or those with no saved image yet. A slide deleted
// from its deck can't be captured.
export function captureTargets(db: DatabaseSync, which: 'all' | 'missing'): CaptureTarget[] {
  const rows = db
    .prepare(
      `SELECT DISTINCT dp.canva_deck_id AS deckId, dp.canva_page_id AS pageId, sc.image_path AS imagePath
       FROM dance_prefs dp
       LEFT JOIN slide_cache sc ON sc.deck_id = dp.canva_deck_id AND sc.page_id = dp.canva_page_id
       WHERE dp.canva_deck_id IS NOT NULL AND dp.canva_page_id IS NOT NULL
       ORDER BY dp.canva_deck_id, dp.canva_page_id`
    )
    .all() as { deckId: number; pageId: string; imagePath: string | null }[]
  return rows.flatMap((r) => {
    if (which === 'missing' && r.imagePath !== null) return []
    const deck = deckRow(db, r.deckId)
    const index = pagesOf(deck).findIndex((p) => p.id === r.pageId)
    return index < 0
      ? []
      : [{ deckId: r.deckId, pageId: r.pageId, viewUrl: deck.viewUrl, position: index + 1 }]
  })
}

export function recordCapture(

  deckId: number,
  pageId: string,
  imagePath: string
): void {

     VALUES (?, ?, ?, ${NOW}, NULL)
     ON CONFLICT (deck_id, page_id) DO UPDATE SET image_path = excluded.image_path,
       captured_at = excluded.captured_at, last_error = NULL`
  ).run(deckId, pageId, imagePath)
}

export function recordCaptureError(

  deckId: number,
  pageId: string,
  message: string

  db.prepare(
    `INSERT INTO slide_cache (deck_id, page_id, last_error) VALUES (?, ?, ?)
     ON CONFLICT (deck_id, page_id) DO UPDATE SET last_error = excluded.last_error`
  ).run(deckId, pageId, message)
}

export function slideImagePath(db: DatabaseSync, deckId: number, pageId: string): string | null {
  const row = db
    .prepare('SELECT image_path AS imagePath FROM slide_cache WHERE deck_id = ? AND page_id = ?')
    .get(deckId, pageId) as { imagePath: string | null } | undefined
  return row?.imagePath ?? null
```

```ts
import { CanvaError } from './decks'
import { isShortLink, pageFromEditLink } from './canva-url'
import { parseDeckPage, type ParsedDeck } from './deck-parser'

// The subset of fetch the client uses (Electron's net.fetch, or a fake in tests).
export type Fetcher = (
  url: string,
  init: { redirect: 'follow' | 'manual'; headers: Record<string, string> }
) => Promise<{
  status: number
  text(): Promise<string>
  headers: { get(name: string): string | null }
}>

// Canva serves the public view page to browsers; ask like one.
const HEADERS = {
  'User-Agent':
    'Mozilla/5.0 (Macintosh; Intel Mac OS X 14_0) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/130.0 Safari/537.36',
  Accept: 'text/html'
}

async function get(fetcher: Fetcher, url: string, redirect: 'follow' | 'manual') {
  try {
    return await fetcher(url, { redirect, headers: HEADERS })
  } catch {
    throw new CanvaError("Couldn't reach Canva. Check the internet connection.")
  }
}

// Fetches and reads a deck's public view page (no Canva login).
export async function fetchDeck(fetcher: Fetcher, viewUrl: string): Promise<ParsedDeck> {
  const response = await get(fetcher, viewUrl, 'follow')
  if (response.status !== 200) {
    throw new CanvaError(
      `Canva didn't return the deck (HTTP ${response.status}). Is its link public?`
    )
  }
  return parseDeckPage(await response.text())
}

// The design and page a page link from Canva's share menu names: a canva.link short link (which
// redirects to the editor link), or the editor link itself.
export async function resolvePageLink(
  fetcher: Fetcher,
  input: string
): Promise<{ designId: string; pageId: string }> {
  let link = input.trim()
  if (isShortLink(link)) {
    const response = await get(fetcher, link, 'manual')
    const location = response.headers.get('location')
    if (!location) throw new CanvaError("That short link didn't lead to a Canva page.")
    link = location
  }
  const page = pageFromEditLink(link)
  if (!page)
    throw new CanvaError("That isn't a link to one slide. Copy it from Canva's Share menu.")
  return page
}
```

```ts
import type { DatabaseSync } from 'node:sqlite'
import type { RefreshSummary } from '@shared/canva'
import { fetchDeck, resolvePageLink, type Fetcher } from './canva-client'
import { normalizeDeckUrl } from './canva-url'
import {
  applyRefresh,
  CanvaError,
  captureTargets,
  deckByDesign,
  listDecks,
  saveDeck,
  setDanceSlide,
  setDanceSlideByPage,
  type CaptureTarget
} from './decks'

// What the control window asks of Canva (spec §6.3, §8.3): add decks, link slides, refresh.
// Linking a slide captures its image; a refresh re-reads every deck and re-captures linked slides.
export class CanvaService {
  constructor(
    private readonly deps: {
      db: DatabaseSync
      fetcher: Fetcher
      queue: { enqueue(targets: CaptureTarget[]): void }
      onChange(): void // decks or a dance's slide changed
    }
  ) {}

  async addDeck(input: string): Promise<number> {
    const link = normalizeDeckUrl(input)
    if (!link) throw new CanvaError("Paste the deck's public view link (it ends in /view).")
    const id = saveDeck(this.deps.db, link, await fetchDeck(this.deps.fetcher, link.viewUrl))
    this.deps.onChange()
    return id
  }

  linkSlide(danceId: number, deckId: number, position: number): void {
    const pageId = setDanceSlide(this.deps.db, danceId, deckId, position)
    this.captureLinked(deckId, pageId)
    this.deps.onChange()
  }

  // A page link from Canva's share menu. A slide added in Canva since the deck was read is found
  // after re-reading the deck once.
  async linkPageLink(danceId: number, input: string): Promise<void> {
    const { designId, pageId } = await resolvePageLink(this.deps.fetcher, input)
    try {
      setDanceSlideByPage(this.deps.db, danceId, designId, pageId)
    } catch (err) {
      const deck = deckByDesign(this.deps.db, designId)
      if (!deck || !(err instanceof CanvaError) || !err.message.includes("isn't in the deck"))
        throw err
      await this.refreshDeck(deck.id, deck.viewUrl)
      setDanceSlideByPage(this.deps.db, danceId, designId, pageId)
    }
    this.captureLinked(deckByDesign(this.deps.db, designId)!.id, pageId)
    this.deps.onChange()
  }

  async refreshDecks(): Promise<RefreshSummary> {
    const summary = { decks: 0, formatChanged: 0, unreachable: 0 }
    for (const deck of listDecks(this.deps.db)) {
      const result = await this.refreshDeck(deck.id, deck.viewUrl)
      summary.decks++
      if (result === 'format-changed') summary.formatChanged++
      if (result === 'unreachable') summary.unreachable++
    }
    this.deps.onChange()
    return summary
  }

  // "Refresh slides": re-read every deck, then re-capture every linked slide.
  async refreshSlides(): Promise<RefreshSummary> {
    const summary = await this.refreshDecks()
    this.deps.queue.enqueue(captureTargets(this.deps.db, 'all'))
    return summary
  }

  // At startup, when online: re-read the decks and capture linked slides that have no image yet.
  async startup(online: boolean): Promise<void> {
    if (!online) return
    await this.refreshDecks()
    this.deps.queue.enqueue(captureTargets(this.deps.db, 'missing'))
  }

  private async refreshDeck(deckId: number, viewUrl: string) {
    try {
      return applyRefresh(this.deps.db, deckId, {
        parsed: await fetchDeck(this.deps.fetcher, viewUrl)
      })
    } catch (err) {
      return applyRefresh(this.deps.db, deckId, {
        error: err instanceof Error ? err.message : String(err)
      })
    }
  }

  private captureLinked(deckId: number, pageId: string): void {
    const target = captureTargets(this.deps.db, 'all').find(
      (t) => t.deckId === deckId && t.pageId === pageId
    )
    if (target) this.deps.queue.enqueue([target])
  }
}
```

```ts
import type { DatabaseSync } from 'node:sqlite'
import { join } from 'node:path'
import { CAPTURES_IDLE, type CaptureStatus } from '@shared/canva'
import { recordCapture, recordCaptureError, type CaptureTarget } from './decks'

// Takes the picture of one slide (main/index.ts: an off-screen Canva view, nudged so Canva's
// controls fade, then captured). close() frees it once the queue is empty.
export interface SlideCapturer {
  capture(target: CaptureTarget): Promise<Buffer>
  close(): void
}

export interface CaptureDeps {
  db: DatabaseSync
  capturer: SlideCapturer
  slidesDir: string
  writeFile(path: string, data: Buffer): Promise<void>
  onStatus(status: CaptureStatus): void
  onCaptured(): void // a slide image was saved or failed: the library and projector refresh
}

const key = (t: CaptureTarget) => `${t.deckId}/${t.pageId}`

// Captures slides one at a time in the background (spec §8.3). Each image is saved under the app
// data folder, keyed by deck and page ID, so a moved slide keeps its image. A failure keeps the
// previous image and records why.
export class CaptureQueue {
  private pending: CaptureTarget[] = []
  private status: CaptureStatus = CAPTURES_IDLE
  private running: Promise<void> | null = null

  constructor(private readonly deps: CaptureDeps) {}

  current(): CaptureStatus {
    return this.status
  }

  enqueue(targets: CaptureTarget[]): void {
    const queued = new Set(this.pending.map(key))
    const fresh = targets.filter((t) => !queued.has(key(t)) && queued.add(key(t)))
    if (fresh.length === 0) return
    this.pending.push(...fresh)
    // A new batch starts counting from zero; one still running grows.
    const base = this.status.running ? this.status : CAPTURES_IDLE
    this.update({ ...base, running: true, total: base.total + fresh.length })
    this.running ??= this.run().finally(() => (this.running = null))
  }

  // Resolves when every queued capture has finished.
  async idle(): Promise<void> {
    while (this.running) await this.running
  }

  private async run(): Promise<void> {
    for (let target = this.pending.shift(); target; target = this.pending.shift()) {
      try {
        const image = await this.deps.capturer.capture(target)
        const path = join(this.deps.slidesDir, `${target.deckId}-${target.pageId}.png`)
        await this.deps.writeFile(path, image)
        recordCapture(this.deps.db, target.deckId, target.pageId, path)
        this.update({ done: this.status.done + 1 })
      } catch (err) {
        recordCaptureError(
          this.deps.db,
          target.deckId,
          target.pageId,
          err instanceof Error ? err.message : String(err)
        )
        this.update({ done: this.status.done + 1, failed: this.status.failed + 1 })
      }
      this.deps.onCaptured()
    }
    this.deps.capturer.close()
    this.update({ running: false })
  }

  private update(change: Partial<CaptureStatus>): void {
    this.status = { ...this.status, ...change }
    this.deps.onStatus(this.status)
  }
}
```

```ts
import type { SlideCapturer } from './capture-queue'
import type { CaptureTarget } from './decks'

// An off-screen Canva page (main/index.ts: an off-screen BrowserWindow in the Canva session).
export interface CanvaPage {
  load(url: string): Promise<void> // resolves once the page has loaded
  nudge(): void // a synthetic mouse pass, so Canva starts fading its controls
  capture(): Promise<Buffer> // a PNG of the page as it looks now
  destroy(): void
}

// Canva fades its controls about 10 s after the last mouse activity. Within a loaded deck a slide
// change happens in the page and the controls stay hidden; it needs only a moment to draw.
const FADE_MS = 12_000
const SLIDE_CHANGE_MS = 1_500
const TIMEOUT_MS = 45_000

// Spec §8.3: one page, reused while slides of the same deck are captured in turn.
export function createSlideCapturer(deps: {
  createPage: () => CanvaPage
  sleep: (ms: number) => Promise<void>
  timeoutMs?: number
}): SlideCapturer {
  let page: CanvaPage | null = null
  let deckUrl: string | null = null
  const close = (): void => {
    page?.destroy()
    page = null
    deckUrl = null
  }
  const capture = async (target: CaptureTarget): Promise<Buffer> => {
    const sameDeck = page !== null && deckUrl === target.viewUrl
    page ??= deps.createPage()
    const current = page
    deckUrl = null // until this load succeeds
    await current.load(`${target.viewUrl}#${target.position}`)
    deckUrl = target.viewUrl
    if (!sameDeck) current.nudge()
    await deps.sleep(sameDeck ? SLIDE_CHANGE_MS : FADE_MS)
    return current.capture()
  }
  return {
    capture: (target) => {
      let timer: ReturnType<typeof setTimeout> | undefined
      const timeout = new Promise<never>((_, reject) => {
        timer = setTimeout(() => {
          close() // a page stuck loading is thrown away
          reject(new Error("Canva didn't respond in time"))
        }, deps.timeoutMs ?? TIMEOUT_MS)
      })
      return Promise.race([capture(target), timeout]).finally(() => clearTimeout(timer))
    },
    close
  }
}
```

```ts
// only renders it.
import type { LabelParts } from './labels'

// One dance: the dance (and choreographer, when the label needs it) large; the song smaller, only
// when it differs; the country on the right.
export interface ProjectorEntry {
  parts: LabelParts
  country: string | null
}

// The upcoming list: dances, and "Teaching" before a dance that will be taught (a STOP marker).
export type UpcomingRow = { kind: 'dance'; entry: ProjectorEntry } | { kind: 'teaching' }

// The middle dance's Canva slide (spec §8.3): its saved image, and whether main's live view of it
// is showing over the slide area. The projector uses the slide layout when either is available.
export interface ProjectorSlide {
  deckId: number
  pageId: string
  imageUrl: string | null // fdp-media://slide/<deck>/<page>, when an image is saved
  live: boolean
}

export type ProjectorMiddle =
  // The song that's loaded: playing, paused, or stopped (rewound, ▶ plays it again).
  (
    | { kind: 'now'; entry: ProjectorEntry; playId: number; paused: boolean }
    // Nothing loaded: the next dance, with the countdown before it, if one is running.
    | {
        kind: 'next'
        entry: ProjectorEntry
        countdown: { secondsLeft: number; reason: 'start' | 'continue' } | null
        teaching: boolean // a STOP comes before it: it's the dance to be taught
      }
  ) & { slide?: ProjectorSlide }

export interface Rect {
  x: number
  y: number
  width: number
  height: number
}

// Where the slide sits on the projector (spec §8.2): top right, 16:9, filling up to two-thirds of
// the width and the top half of the height, inside the view's margins. The projector page draws
// the saved image there, and main lays its live Canva view over exactly the same box.
export function slideBox(width: number, height: number): Rect {
  const padX = width * 0.04
  const padY = height * 0.03
  const areaWidth = ((width - 2 * padX) * 2) / 3
  const areaHeight = height * 0.5 - padY
  let w = areaWidth
  let h = (w * 9) / 16
  if (h > areaHeight) {
    h = areaHeight
    w = (h * 16) / 9
  }
  return {
    x: Math.round(width - padX - w),
    y: Math.round(padY),
    width: Math.round(w),
    height: Math.round(h)
  }
}
```

```ts
import type { PlayedEntry, PlayerState, ProgramItem, Track } from '@shared/program'
import type {
  ProjectorEntry,
  ProjectorSlide,
  ProjectorSnapshot,
  UpcomingRow
} from '@shared/projector'

const entry = (track: Track): ProjectorEntry => ({ parts: track.parts, country: track.country })

// Upcoming rows from program items: songs, and one "Teaching" row before a song that follows STOP
// markers. Songs whose file is missing are left out (they'll be skipped), and so is a STOP with no
// song after it.
function upcomingRows(items: ProgramItem[]): UpcomingRow[] {
  const rows: UpcomingRow[] = []
  let teaching = false
  for (const item of items) {
    if (item.kind === 'stop') {
      teaching = true
    } else if (!item.isMissing) {
      if (teaching) rows.push({ kind: 'teaching' })
      teaching = false
      rows.push({ kind: 'dance', entry: entry(item) })
    }
  }
  return rows
}

// Spec §8.2: what the projector shows, from the player, the loaded program's unplayed items and its
// play log (which includes previews and replays). `slideFor` gives the middle dance's Canva slide.
export function buildProjectorSnapshot(
  player: PlayerState,
  unplayed: ProgramItem[],
  played: PlayedEntry[],
  slideFor: (danceId: number | null) => ProjectorSlide | null = () => null
): ProjectorSnapshot {
  const withSlide = (track: Track) => {
    const slide = slideFor(track.danceId)
    return slide ? { slide } : {}
  }
  const { current } = player
  const loaded = current && player.status !== 'idle' && player.status !== 'countdown'
  // The song playing now is the newest log entry; it shows in the middle, not twice.
  const history = played.flatMap((p) =>
    p.track && !(loaded && p.logId === current.logId) ? [entry(p.track)] : []
  )
  if (loaded) {
    return {
      hasProgram: player.programId !== null,
      middle: {
        kind: 'now',
        entry: entry(current.track),
        playId: current.playId,
        paused: player.status !== 'playing',
        ...withSlide(current.track)
      },
      upcoming: upcomingRows(unplayed),
      played: history
    }
  }
  // Nothing loaded: the next song that will play is the middle; what's after it, the list.
  const index = unplayed.findIndex((i) => i.kind === 'track' && !i.isMissing)
  const next = index < 0 ? null : (unplayed[index] as Extract<ProgramItem, { kind: 'track' }>)
  const stopBefore = unplayed.slice(0, Math.max(index, 0)).some((i) => i.kind === 'stop')
  return {
    hasProgram: player.programId !== null,
    middle: next && {
      kind: 'next',
      entry: entry(next),
      countdown: player.countdown,
      teaching: player.atStop || stopBefore,
      ...withSlide(next)
    },
    upcoming: next ? upcomingRows(unplayed.slice(index + 1)) : [],
    played: history
  }
}
```

```ts
import { slideBox, type Rect } from '@shared/projector'

// The Canva page shown over the projector's slide area: a WebContentsView in Electron.
export interface LiveView {
  load(url: string): Promise<void> // resolves once the page has loaded
  nudge(): void // a synthetic mouse pass, so Canva starts fading its controls
  setVisible(visible: boolean): void
  setBounds(bounds: Rect): void
  destroy(): void
}

export interface LiveTarget {
  deckId: number
  viewUrl: string
  pageId: string
  position: number
}

// Canva fades its controls about 10 s after the last mouse activity; a slide change within a
// loaded deck needs only a moment to draw.
const FADE_MS = 11_000
const HASH_FADE_MS = 1_500

// Spec §8.3, "saved image, then live": the projector page shows the saved image at once, and the
// live view stays hidden until its controls have faded, then covers the image exactly. Offline, or
// when the page fails to load, it never shows. `onChange` fires when the view appears or goes.
export class LiveSlide {
  private view: LiveView | null = null
  private deckUrl: string | null = null // the deck the view has loaded
  private target: LiveTarget | null = null
  private live = false
  private generation = 0
  private timer: ReturnType<typeof setTimeout> | null = null

  constructor(
    private readonly deps: {
      createView: () => LiveView
      online: () => boolean
      size: () => { width: number; height: number } | null // the projector window's content
      onChange: () => void
    }
  ) {}

  show(target: LiveTarget | null): void {
    if (target && this.target && same(target, this.target)) return
    const wasLive = this.live
    this.cancel()
    this.target = target
    if (!target || !this.deps.online()) {
      this.view?.setVisible(false)
      if (wasLive) this.deps.onChange()
      return
    }
    const sameDeck = this.view !== null && this.deckUrl === target.viewUrl
    if (!this.view) {
      this.view = this.deps.createView()
      this.resize()
    }
    const view = this.view
    view.setVisible(false)
    if (wasLive) this.deps.onChange()
    this.deckUrl = target.viewUrl
    const generation = this.generation
    view.load(`${target.viewUrl}#${target.position}`).then(
      () => {
        if (generation !== this.generation) return
        if (!sameDeck) view.nudge()
        this.timer = setTimeout(
          () => {
            this.timer = null
            this.live = true
            view.setVisible(true)
            this.deps.onChange()
          },
          sameDeck ? HASH_FADE_MS : FADE_MS
        )
      },
      () => {
        if (generation === this.generation) this.deckUrl = null // try a full load next time
      }
    )
  }

  // Whether the live view is showing this slide.
  isLive(target: Pick<LiveTarget, 'deckId' | 'pageId'>): boolean {
    return this.live && this.target !== null && same(target, this.target)
  }

  resize(): void {
    const size = this.deps.size()
    if (size && this.view) this.view.setBounds(slideBox(size.width, size.height))
  }

  // The projector window closed.
  close(): void {
    this.cancel()
    this.view?.destroy()
    this.view = null
    this.deckUrl = null
    this.target = null
  }

  private cancel(): void {
    this.generation++
    if (this.timer) clearTimeout(this.timer)
    this.timer = null
    this.live = false
  }
}

const same = (a: Pick<LiveTarget, 'deckId' | 'pageId'>, b: Pick<LiveTarget, 'deckId' | 'pageId'>) =>
  a.deckId === b.deckId && a.pageId === b.pageId
```

```ts
      `SELECT d.id AS danceId, ds.id AS pairingId, d.name, d.country, d.choreographer,
         d.dance_type AS danceType, dp.difficulty, dp.notes, dsp.teacher,
         (SELECT COUNT(*) FROM dance_songs c WHERE c.dance_id = d.id) AS songCount,
         ds.id = ? AS isDefault
       FROM dance_songs ds JOIN dances d ON d.id = ds.dance_id
       LEFT JOIN dance_prefs dp ON dp.dance_id = d.id
       LEFT JOIN dance_song_prefs dsp ON dsp.dance_song_id = ds.id
       WHERE ds.song_id = ?
       ORDER BY isDefault DESC, ds.id`
    )
    .all(song.shownPairingId, songId) as unknown as DanceRow[]

  const choreographerCount = new Set(
    rows.map((r) => r.choreographer?.trim()).filter((c): c is string => !!c)
  ).size
  const dances: SongDance[] = rows.map((r) => ({
    ...r,
    isDefault: r.isDefault === 1,
    slide: getDanceSlide(db, r.danceId),
    label: formatLabel(
      labelParts({
        songTitle: song.title,
        danceName: r.name,
        choreographer: r.choreographer,
        choreographerCount
      })
    )
  }))

  const { shownPairingId: _, isMissing, isFavorite, ...rest } = song
  return {
    ...rest,
    isMissing: isMissing === 1,
    isFavorite: isFavorite === 1,
    dances,
    suggestions: sameNameSuggestions(db, songId, dances)
  }
}

// Other dances with the same name (ignoring case and surrounding spaces) that aren't linked to
// this song, are used by at least one song, and weren't marked "different" (spec §6.3).
function sameNameSuggestions(
  db: DatabaseSync,
  songId: number,
  dances: SongDance[]
): SameNameSuggestion[] {
  const candidates = db.prepare(
    `SELECT c.id AS danceId, c.name, c.choreographer, c.country FROM dances c
     WHERE lower(trim(c.name)) = lower(trim(?)) AND c.id <> ?
       AND c.id NOT IN (SELECT dance_id FROM dance_songs WHERE song_id = ?)
       AND EXISTS (SELECT 1 FROM dance_songs u WHERE u.dance_id = c.id)
       AND NOT EXISTS (SELECT 1 FROM distinct_dances x
         WHERE x.dance_a = min(c.id, ?) AND x.dance_b = max(c.id, ?))
     ORDER BY c.id`
  )
  const titles = db.prepare(
    `SELECT s.title FROM dance_songs ds JOIN songs s ON s.id = ds.song_id
     WHERE ds.dance_id = ? ORDER BY s.title COLLATE NOCASE`
  )
  return dances.flatMap((d) =>
    (
      candidates.all(
        d.name,
        d.danceId,
        songId,
        d.danceId,
        d.danceId
      ) as unknown as SameNameSuggestion['candidate'][]
    ).map((c) => ({
      forDanceId: d.danceId,
      candidate: { ...c, songTitles: titles.all(c.danceId).map((t) => t.title as string) }
    }))
  )
}

// Folds case, accents and letters like ı/ł/ø so "pasa" matches "Paşa".
const normalize = (text: string): string =>
  (foldSearchText(text) ?? '').normalize('NFKD').replace(/\p{M}/gu, '').toLowerCase()

export function searchDances(db: DatabaseSync, text: string, limit = 50): DanceSearchResult[] {
  const words = normalize(text).split(/\s+/).filter(Boolean)
  const rows = db
    .prepare(
      `SELECT d.id AS danceId, d.name, d.choreographer, d.country,
         (SELECT COUNT(*) FROM dance_songs c WHERE c.dance_id = d.id) AS songCount
       FROM dances d ORDER BY d.name COLLATE NOCASE, d.id`
    )
    .all() as unknown as DanceSearchResult[]
  return rows
    .filter((d) => {
      const haystack = normalize([d.name, d.choreographer, d.country].filter(Boolean).join(' '))
      return words.every((w) => haystack.includes(w))
    })
    .slice(0, limit)
}

export function updateDance(db: DatabaseSync, danceId: number, patch: DancePatch): void {
  const facts: Record<string, unknown> = {}
  if (patch.name !== undefined) facts.name = required(patch.name, 'A dance name')
  if (patch.country !== undefined) facts.country = optional(patch.country)
  if (patch.choreographer !== undefined) facts.choreographer = optional(patch.choreographer)
  if (patch.danceType !== undefined) facts.dance_type = optional(patch.danceType)
  const prefs: Record<string, unknown> = {}
  if (patch.difficulty !== undefined) {
    if (
      patch.difficulty !== null &&
      !(Number.isInteger(patch.difficulty) && patch.difficulty >= 1 && patch.difficulty <= 5)

  if (patch.notes !== undefined) prefs.notes = optional(patch.notes)

    update(db, 'dances', 'id', danceId, facts)
    if (Object.keys(prefs).length) {

      update(db, 'dance_prefs', 'dance_id', danceId, prefs)
    }
  })

const isLinked = (db: DatabaseSync, songId: number, danceId: number): boolean =>
  !!db.prepare('SELECT 1 FROM dance_songs WHERE song_id = ? AND dance_id = ?').get(songId, danceId)

export function setDefaultDance(db: DatabaseSync, songId: number, danceId: number | null): void {
  if (danceId !== null && !isLinked(db, songId, danceId)) {
    throw new LibraryEditError('That dance is not linked to this song.')
  }
  db.prepare(
    `INSERT INTO song_prefs (song_id, default_dance_id) VALUES (?, ?)
     ON CONFLICT (song_id) DO UPDATE SET default_dance_id = excluded.default_dance_id`
  ).run(songId, danceId)
}

// The song's first dance becomes its default.
function linkAndMaybeDefault(db: DatabaseSync, songId: number, danceId: number): void {
  const hadDances = !!db.prepare('SELECT 1 FROM dance_songs WHERE song_id = ?').get(songId)
  db.prepare('INSERT OR IGNORE INTO dance_songs (dance_id, song_id) VALUES (?, ?)').run(
    danceId,
    songId
  )
  if (!hadDances) setDefaultDance(db, songId, danceId)
}

export function linkDance(db: DatabaseSync, songId: number, danceId: number): void {
  inTransaction(db, () => linkAndMaybeDefault(db, songId, danceId))
}

export function createDance(db: DatabaseSync, songId: number, name: string): number {
  const danceName = required(name, 'A dance name')
  return inTransaction(db, () => {
    const danceId = Number(
      db.prepare('INSERT INTO dances (uuid, name) VALUES (?, ?)').run(randomUUID(), danceName)
        .lastInsertRowid
    )
    linkAndMaybeDefault(db, songId, danceId)
    return danceId
  })
}

// Removes the link only; the dance itself is kept (spec §4: a dance with no songs is kept).
export function unlinkDance(db: DatabaseSync, songId: number, danceId: number): void {
  inTransaction(db, () => {
    db.prepare('DELETE FROM dance_songs WHERE song_id = ? AND dance_id = ?').run(songId, danceId)
    const current = db
      .prepare('SELECT default_dance_id AS id FROM song_prefs WHERE song_id = ?')
      .get(songId) as { id: number | null } | undefined
    if (current?.id === danceId) {
      const next = db
        .prepare('SELECT dance_id AS id FROM dance_songs WHERE song_id = ? ORDER BY id LIMIT 1')
        .get(songId) as { id: number } | undefined
      setDefaultDance(db, songId, next?.id ?? null)
    }
  })
}

// Combines `removeId` into `keepId`: its songs (with their teachers), song defaults, program items
// and history move to the kept dance; the kept dance's empty fields are filled from it.
export function mergeDances(db: DatabaseSync, keepId: number, removeId: number): void {
  if (keepId === removeId) throw new LibraryEditError("A dance can't be merged into itself.")
  inTransaction(db, () => {
    const links = db
      .prepare(
        `SELECT ds.id, ds.song_id AS songId, p.teacher FROM dance_songs ds
         LEFT JOIN dance_song_prefs p ON p.dance_song_id = ds.id WHERE ds.dance_id = ? ORDER BY ds.id`
      )
      .all(removeId) as unknown as { id: number; songId: number; teacher: string | null }[]
    for (const l of links) {
      db.prepare('DELETE FROM dance_songs WHERE id = ?').run(l.id)
      db.prepare('INSERT OR IGNORE INTO dance_songs (dance_id, song_id) VALUES (?, ?)').run(
        keepId,
        l.songId
      )
      if (l.teacher) {
        const kept = db
          .prepare('SELECT id FROM dance_songs WHERE dance_id = ? AND song_id = ?')
          .get(keepId, l.songId) as { id: number }
        const existing = db
          .prepare('SELECT teacher FROM dance_song_prefs WHERE dance_song_id = ?')
          .get(kept.id) as { teacher: string | null } | undefined
        if (!existing?.teacher) setTeacher(db, kept.id, l.teacher)
      }
    }
    for (const table of ['song_prefs', 'program_items', 'play_log']) {
      const col = table === 'song_prefs' ? 'default_dance_id' : 'dance_id'
      db.prepare(`UPDATE ${table} SET ${col} = ? WHERE ${col} = ?`).run(keepId, removeId)
    }
    fillEmptyFrom(db, 'dances', 'id', keepId, removeId, ['country', 'choreographer', 'dance_type'])
    db.prepare('INSERT OR IGNORE INTO dance_prefs (dance_id) VALUES (?)').run(keepId)
    // Notes are never dropped: when both dances have them, the removed dance's are appended.
    const notesOf = (id: number): string =>
      (
        (
          db.prepare('SELECT notes FROM dance_prefs WHERE dance_id = ?').get(id) as
            { notes: string | null } | undefined
        )?.notes ?? ''
      ).trim()
    const [keptNotes, removedNotes] = [notesOf(keepId), notesOf(removeId)]
    if (keptNotes && removedNotes && keptNotes !== removedNotes) {
      update(db, 'dance_prefs', 'dance_id', keepId, { notes: `${keptNotes}\n\n${removedNotes}` })
    }
    fillEmptyFrom(db, 'dance_prefs', 'dance_id', keepId, removeId, [
      'difficulty',
      'notes',
      'canva_deck_id',
      'canva_page_id',
      'canva_page_index'
    ])
    // "Different dance" answers about the removed dance now apply to the kept one.
    db.prepare(
      `INSERT OR IGNORE INTO distinct_dances (dance_a, dance_b)
       SELECT min(?, other), max(?, other) FROM (
         SELECT dance_b AS other FROM distinct_dances WHERE dance_a = ?
         UNION SELECT dance_a FROM distinct_dances WHERE dance_b = ?)
       WHERE other <> ?`
    ).run(keepId, keepId, removeId, removeId, keepId)
    db.prepare('DELETE FROM dances WHERE id = ?').run(removeId)
  })
}

function fillEmptyFrom(
  db: DatabaseSync,
  table: string,
  key: string,
  keepId: number,
  fromId: number,
  cols: string[]
): void {
  const read = db.prepare(`SELECT ${cols.join(', ')} FROM ${table} WHERE ${key} = ?`)
  const keep = read.get(keepId) as Record<string, unknown> | undefined
  const from = read.get(fromId) as Record<string, unknown> | undefined
  if (!keep || !from) return
  const fill = Object.fromEntries(
    cols.filter((c) => (keep[c] ?? '') === '' && (from[c] ?? '') !== '').map((c) => [c, from[c]])
  )
  update(db, table, key, keepId, fill)
}

// "Same dance" on a suggestion (spec §6.3): the song is linked to `otherId` and it becomes the
// default. The song's own dance is merged into it when no other song uses it.
export function sameDance(db: DatabaseSync, songId: number, ownId: number, otherId: number): void {
  inTransaction(db, () => {
    const ownSongs = (
      db.prepare('SELECT COUNT(*) AS n FROM dance_songs WHERE dance_id = ?').get(ownId) as {
        n: number
      }
    ).n
    if (ownSongs <= 1) {
      mergeDances(db, otherId, ownId)
    } else {
      linkAndMaybeDefault(db, songId, otherId)
    }
    setDefaultDance(db, songId, otherId)
  })
}

// "Different dance": remember the pair so the suggestion isn't shown again.
export function markDifferentDances(db: DatabaseSync, a: number, b: number): void {
  db.prepare('INSERT OR IGNORE INTO distinct_dances (dance_a, dance_b) VALUES (?, ?)').run(
    Math.min(a, b),
    Math.max(a, b)
  )
}
```

```ts
// The two WebContents methods the guards need (Electron's WebContents satisfies this).
export interface NavigableContents {
  on(
    event: 'will-navigate',
    listener: (event: { preventDefault(): void; url: string }) => void
  ): unknown
  setWindowOpenHandler(handler: () => { action: 'deny' }): void
}

// The app is a single page: it never navigates or opens windows. Without this guard, a file
// dropped outside the drop zone makes Chromium load it, replacing the app with a media viewer.
export function guardNavigation(contents: NavigableContents): void {
  contents.on('will-navigate', (event) => event.preventDefault())
  contents.setWindowOpenHandler(() => ({ action: 'deny' }))
}

export function isCanvaUrl(url: string): boolean {
  try {
    const { protocol, hostname } = new URL(url)
    return protocol === 'https:' && (hostname === 'canva.com' || hostname.endsWith('.canva.com'))
  } catch {
    return false
  }
}

// The Canva views (live and capture) show web content: they may move around canva.com, and
// nothing else.
export function guardCanva(contents: NavigableContents): void {
  contents.on('will-navigate', (event) => {
    if (!isCanvaUrl(event.url)) event.preventDefault()
  })
  contents.setWindowOpenHandler(() => ({ action: 'deny' }))
}
```

```ts
import type { ProjectorProgress, ProjectorSlide, ProjectorSnapshot } from '@shared/projector'
import { getDanceSlide } from '../canva/decks'

export interface ProjectorFeed {
  snapshot(): ProjectorSnapshot
  update(): void // after the player, the programs or the library changed
  progress(progress: ProjectorProgress): void
}

// What the projector window is sent (spec §8.2, §9): the snapshot when anything it shows may have
// changed, and the playing song's position (from the control window, about 4 times a second).
// Each snapshot also tells the live Canva view which slide to show (spec §8.3).
export function createProjectorFeed(deps: {
  db: DatabaseSync
  player: Pick<PlayerSession, 'getState'>
  projector: Pick<ProjectorController, 'status' | 'send'>
  live: Pick<LiveSlide, 'show' | 'isLive'>
}): ProjectorFeed {
  const snapshot = (): ProjectorSnapshot => {
    const state = deps.player.getState()
    const id = state.programId
    let shown = false
    const slideFor = (danceId: number | null): ProjectorSlide | null => {
      const slide = danceId === null ? null : getDanceSlide(deps.db, danceId)
      // A slide gone from its deck can't be shown live; its saved image still can.
      const live =
        slide?.status === 'ok'
          ? {
              deckId: slide.deckId,
              viewUrl: slide.viewUrl,
              pageId: slide.pageId,
              position: slide.position!
            }
          : null
      deps.live.show(live)
      shown = true
      if (!slide || (!slide.imageUrl && !live)) return null
      return {
        deckId: slide.deckId,
        pageId: slide.pageId,
        imageUrl: slide.imageUrl,
        live: live !== null && deps.live.isLive(live)
      }
    }
    const snap = buildProjectorSnapshot(
      state,
      id === null ? [] : (getProgram(deps.db, id)?.items ?? []),
      id === null ? [] : listPlayed(deps.db, id),
      slideFor
    )
    if (!shown) deps.live.show(null)
    return snap
  }
  return {
    snapshot,
    update: () => {
      if (deps.projector.status().open) deps.projector.send('projector:snapshot', snapshot())
    },
    progress: (progress) => deps.projector.send('projector:progress', progress)
  }
}
```

```ts
const CANVA_PREFERENCES = { partition: 'persist:canva', sandbox: true }

// A mouse pass across the page and out: Canva shows its controls, then fades them ~10 s later.
function nudge(contents: WebContents, width: number, height: number): void {
  const points = [
    [0.2, 0.3],
    [0.5, 0.5],
    [0.8, 0.75]
  ]
  points.forEach(([x, y], i) =>
    setTimeout(() => {
      if (contents.isDestroyed()) return
      contents.sendInputEvent({
        type: 'mouseMove',
        x: Math.round(x * width),
        y: Math.round(y * height)
      })
      if (i === points.length - 1) contents.sendInputEvent({ type: 'mouseLeave', x: 0, y: 0 })
    }, i * 150)
  )
}

// Within a loaded deck, loading another #slide only changes the slide in the page.
const load = async (contents: WebContents, url: string): Promise<void> => {
  await contents.loadURL(url)
}

// Spec §8.3: slides are captured at 1920×1080 in an off-screen window.
export function createCanvaPage(): CanvaPage {
  const win = new BrowserWindow({
    width: 1920,
    height: 1080,
    show: false,
    webPreferences: { ...CANVA_PREFERENCES, offscreen: true }
  })
  win.webContents.setAudioMuted(true)
  win.webContents.setFrameRate(10)
  guardCanva(win.webContents)
  return {
    load: (url) => load(win.webContents, url),
    nudge: () => nudge(win.webContents, 1920, 1080),
    capture: async () => {
      if (win.isDestroyed()) throw new Error('The capture window was closed')
      return (await win.webContents.capturePage()).toPNG()
    },
    destroy: () => {
      if (!win.isDestroyed()) win.destroy()
    }
  }
}

// The live Canva page over the projector's slide area (spec §8.3).
export function createLiveView(window: BrowserWindow): LiveView {
  const view = new WebContentsView({ webPreferences: CANVA_PREFERENCES })
  const contents = view.webContents
  contents.setAudioMuted(true)
  view.setBackgroundColor('#000000')
  view.setVisible(false)
  guardCanva(contents)
  window.contentView.addChildView(view)
  let bounds: Rect = { x: 0, y: 0, width: 0, height: 0 }
  return {
    load: (url) => load(contents, url),
    nudge: () => nudge(contents, bounds.width, bounds.height),
    setVisible: (visible) => view.setVisible(visible),
    setBounds: (b) => {
      bounds = b
      view.setBounds(b)
    },
    destroy: () => {
      if (!window.isDestroyed()) window.contentView.removeChildView(view)
      if (!contents.isDestroyed()) contents.close()
    }
  }
```

```tsx
import { useEffect, useState } from 'react'
import type { LabelParts } from '@shared/labels'
import {
  slideBox,
  type ProjectorEntry,
  type ProjectorProgress,
  type ProjectorSnapshot
} from '@shared/projector'
import { ChevronDownIcon } from '../components/icons'
import classes from './ProjectorView.module.css'

// The large part of a label: the dance, and the choreographer when the label needs it (spec §4).
const dance = (parts: LabelParts): string =>
  parts.choreographer ? `${parts.dance} (${parts.choreographer})` : parts.dance

// A list row: the dance and (smaller, only when it differs) ♪ the song on the left; the country on
// the right. `titleOnly` (previously played beside a slide, a narrow column) shows just the dance.
function Row({
  entry,
  titleOnly = false
}: {
  entry: ProjectorEntry
  titleOnly?: boolean
}): React.JSX.Element {
  return (
    <li className={classes.row}>
      <span className={classes.name}>
        <span className={classes.dance}>{dance(entry.parts)}</span>
        {!titleOnly && entry.parts.song && (
          <span className={classes.song}>♪ {entry.parts.song}</span>
        )}
      </span>
      {!titleOnly && <span className={classes.country}>{entry.country}</span>}
    </li>
  )
}

// ⌄ —— Teaching —— ⌄, pointing down at the dance that will be taught.
function Teaching({ as: Tag = 'li' }: { as?: 'li' | 'div' }): React.JSX.Element {
  return (
    <Tag className={classes.teaching}>
      <ChevronDownIcon size={28} />
      <span className={classes.rule} />
      <span>Teaching</span>
      <span className={classes.rule} />
      <ChevronDownIcon size={28} />
    </Tag>
  )
}

function percent(snapshot: ProjectorSnapshot, progress: ProjectorProgress | null): number {
  const { middle } = snapshot
  if (middle?.kind !== 'now' || !progress || progress.playId !== middle.playId) return 0
  if (!progress.durationMs) return 0
  return Math.min(100, Math.max(0, (progress.positionMs / progress.durationMs) * 100))
}

function useWindowSize(): { width: number; height: number } {
  const read = () => ({ width: window.innerWidth, height: window.innerHeight })
  const [size, setSize] = useState(read)
  useEffect(() => {
    const update = () => setSize(read())
    window.addEventListener('resize', update)
    return () => window.removeEventListener('resize', update)
  }, [])
  return size
}

// Spec §8.2: previously played across the top, then what's playing (or the next dance), then the
// rest of the program. With a Canva slide (§8.3) the top half is shared: previously played on the
// left, the slide on the right, in the box main lays its live view over. It only renders.
export default function ProjectorView({
  snapshot,
  progress
}: {
  snapshot: ProjectorSnapshot
  progress: ProjectorProgress | null
}): React.JSX.Element {
  const { middle, upcoming, played } = snapshot
  const size = useWindowSize()
  if (!snapshot.hasProgram && !middle) {
    return (
      <div className={classes.screen}>
        <div className={classes.empty}>Folk Dance Player</div>
      </div>
    )
  }
  const nextHeading =
    middle?.kind === 'next' && middle.countdown
      ? middle.countdown.reason === 'start'
        ? `Starting in ${middle.countdown.secondsLeft}…`
        : `Next in ${middle.countdown.secondsLeft}…`
      : 'Up next'
  const slide = middle?.slide
  const box = slide ? slideBox(size.width, size.height) : null
  const playedList = played.length > 0 && (
    <section className={classes.played} aria-label="Previously played">
      <h2 className={classes.heading}>Previously played</h2>
      <ul className={classes.list}>
        {played.map((entry, i) => (
          <Row key={i} entry={entry} titleOnly={box !== null} />
        ))}
      </ul>
    </section>
  )
  return (
    <div className={classes.screen}>
      {slide && box ? (
        <div className={classes.slideRow} style={{ height: box.height }} data-testid="slide-row">
          {playedList || <div />}
          <div
            className={classes.slideArea}
            style={{ width: box.width, height: box.height }}
            data-testid="slide-area"
          >
            {slide.imageUrl && (
              <img
                className={classes.slideImage}
                src={slide.imageUrl}
                alt={`Slide for ${middle.entry.parts.dance}`}
              />
            )}
          </div>
        </div>
      ) : (
        playedList
      )}
      {middle && (
        <section
          className={classes.middle}
          aria-label={middle.kind === 'now' ? 'Now playing' : 'Up next'}
        >
          <h2 className={classes.heading}>
            {middle.kind === 'now' ? 'Now playing' : nextHeading}
            {middle.kind === 'now' && middle.paused && (
              <span className={classes.paused}>Paused</span>
            )}
          </h2>
          {middle.kind === 'next' && middle.teaching && <Teaching as="div" />}
          <div className={classes.nowLine}>
            <span className={classes.nowDance}>{dance(middle.entry.parts)}</span>
            <span className={classes.nowCountry}>{middle.entry.country}</span>
          </div>
          {middle.entry.parts.song && (
            <div className={classes.nowSong}>♪ {middle.entry.parts.song}</div>
          )}
          {middle.kind === 'now' && (
            <div className={classes.track}>
              <div
                className={classes.bar}
                data-testid="progress"
                style={{ width: `${percent(snapshot, progress)}%` }}
              />
            </div>
          )}
        </section>
      )}
      {upcoming.length > 0 && (
        <section
          className={classes.upcoming}
          aria-label={middle?.kind === 'next' ? 'After that' : 'Up next'}
        >
          <h2 className={classes.heading}>{middle?.kind === 'next' ? 'After that' : 'Up next'}</h2>
          <ul className={classes.list}>
            {upcoming.map((row, i) =>
              row.kind === 'teaching' ? <Teaching key={i} /> : <Row key={i} entry={row.entry} />
            )}
          </ul>
        </section>
      )}
    </div>
  )
}
```

```ts
import type { EventChannel, EventContract, InvokeChannel, RendererApi } from '@shared/contract'
import { CAPTURES_IDLE } from '@shared/canva'
import { IDLE_PLAYER_STATE, NO_REMOTE } from '@shared/program'
import { PROJECTOR_OFF } from '@shared/projector'
import { DEFAULT_SETTINGS, type Settings } from '@shared/settings'

type Handler = (...args: never[]) => unknown

export interface FakeApi {
  api: RendererApi
  // Every invoke, as [channel, ...args].
  calls: unknown[][]
  callsTo(channel: InvokeChannel): unknown[][]
  emit<C extends EventChannel>(channel: C, payload: EventContract[C]): void
  settings: Settings
}

// A RendererApi for component tests. `handlers` answer invoke channels (sync or async values,
// or functions of the call's arguments); settings:getAll/settings:set work out of the box.
export function createFakeApi(
  handlers: Partial<Record<InvokeChannel, unknown>> = {},
  paths: string[] = []
): FakeApi {
  const calls: unknown[][] = []
  const listeners = new Map<string, Set<(payload: unknown) => void>>()
  const fake: FakeApi = {
    calls,
    callsTo: (channel) => calls.filter((c) => c[0] === channel).map((c) => c.slice(1)),
    emit: (channel, payload) => listeners.get(channel)?.forEach((l) => l(payload)),
    settings: { ...DEFAULT_SETTINGS },
    api: {
      invoke: (async (channel: InvokeChannel, ...args: unknown[]) => {
        calls.push([channel, ...args])
        if (channel in handlers) {
          const handler = handlers[channel]
          return typeof handler === 'function'
            ? (handler as Handler)(...(args as never[]))
            : handler
        }
        // The library starts empty unless a test says otherwise.
        if (channel === 'library:list' || channel === 'playlists:list') return []
        if (channel === 'library:stats') return { fileCount: 0 }
        if (channel === 'library:suggestions') return { people: [], countries: [], danceTypes: [] }
        // No program is loaded unless a test says otherwise.
        if (channel === 'programs:list' || channel === 'programs:played') return []
        if (channel === 'programs:get') return null
        if (channel === 'player:getState') return IDLE_PLAYER_STATE
        if (channel === 'remote:status') return NO_REMOTE
        // The projector is off, and the control window's progress reports go nowhere.
        if (channel === 'projector:status') return PROJECTOR_OFF
        if (channel === 'projector:displays') return []
        if (channel === 'projector:reportProgress') return undefined
        // No Canva decks, and no slide images being saved.
        if (channel === 'canva:decks') return []
        if (channel === 'canva:captureStatus') return CAPTURES_IDLE
        if (channel === 'settings:getAll') return fake.settings
        if (channel === 'settings:set') {
          const [key, value] = args as [keyof Settings, unknown]
          fake.settings = { ...fake.settings, [key]: value }
          return fake.settings
        }
        throw new Error(`No fake handler for ${channel}`)
      }) as RendererApi['invoke'],
      on: ((channel: string, listener: (payload: unknown) => void) => {
        if (!listeners.has(channel)) listeners.set(channel, new Set())
        listeners.get(channel)!.add(listener)
        return () => listeners.get(channel)!.delete(listener)
      }) as RendererApi['on'],
      getPathsForFiles: () => paths
    }
  }
  return fake
}
```

```tsx
import { useCallback, useEffect, useState } from 'react'
import { Alert, Button, Group, Text } from '@mantine/core'
import {
  CAPTURES_IDLE,
  FORMAT_CHANGED,
  type CanvaDeck,
  type CaptureStatus,
  type RefreshSummary
} from '@shared/canva'
import { errorMessage } from '../ipc-error'
import { useLibraryApi } from './LibraryProvider'

const decks = (n: number) => `${n} ${n === 1 ? 'deck' : 'decks'}`

function summaryNotice(summary: RefreshSummary): string | null {
  if (summary.unreachable === 0) return null
  return `Couldn't reach Canva for ${decks(summary.unreachable)}. Their saved slides stay in use.`
}

export interface SlidesRefreshState {
  hasDecks: boolean
  status: CaptureStatus
  formatChanged: boolean // a deck couldn't be read: "Canva links need checking"
  notice: string | null
  dismissNotice(): void
  refreshing: boolean
  refresh(): Promise<void>
}

// Spec §6.3, §8.3: "Refresh slides" re-reads every deck and re-saves every linked slide's image.
// The Music page shows the button (with the captures' progress) in its header, and the notices
// below it.
export function useSlidesRefresh(): SlidesRefreshState {
  const api = useLibraryApi()
  const [deckList, setDeckList] = useState<CanvaDeck[]>([])
  const [status, setStatus] = useState<CaptureStatus>(CAPTURES_IDLE)
  const [notice, setNotice] = useState<string | null>(null)
  const [refreshing, setRefreshing] = useState(false)

  const loadDecks = useCallback(() => void api.invoke('canva:decks').then(setDeckList), [api])
  useEffect(() => {
    loadDecks()
    void api.invoke('canva:captureStatus').then(setStatus)
    const offLibrary = api.on('library:changed', loadDecks)
    const offStatus = api.on('canva:captureStatus', setStatus)
    return () => {
      offLibrary()
      offStatus()
    }
  }, [api, loadDecks])

  return {
    hasDecks: deckList.length > 0,
    status,
    formatChanged: deckList.some((d) => d.lastError === FORMAT_CHANGED),
    notice,
    dismissNotice: () => setNotice(null),
    refreshing,
    refresh: async () => {
      setRefreshing(true)
      setNotice(null)
      try {
        setNotice(summaryNotice(await api.invoke('canva:refreshSlides')))
      } catch (err) {
        setNotice(errorMessage(err))
      } finally {
        setRefreshing(false)
      }
    }
  }
}

// The button, with the captures' progress beside it; hidden until a deck has been added.
export function SlidesRefreshButton({
  state
}: {
  state: SlidesRefreshState
}): React.JSX.Element | null {
  if (!state.hasDecks) return null
  const { status } = state
  return (
    <Group gap="xs">
      {status.running ? (
        <Text size="sm" c="dimmed">
          Saving slide images… {status.done} of {status.total}
        </Text>
      ) : (
        status.failed > 0 && (
          <Text size="sm" c="orange">
            {status.failed === 1
              ? "1 slide image couldn't be saved."
              : `${status.failed} slide images couldn't be saved.`}
          </Text>
        )
      )}
      <Button variant="default" onClick={state.refresh} loading={state.refreshing}>
        Refresh slides
      </Button>
    </Group>
  )
}

export function SlidesNotices({ state }: { state: SlidesRefreshState }): React.JSX.Element {
  return (
    <>
      {state.formatChanged && (
        <Alert color="yellow" title="Canva links need checking">
          Canva's page format changed, so the slide lists couldn't be read. The saved slides are
          still shown.
        </Alert>
      )}
      {state.notice && (
        <Alert color="orange" withCloseButton onClose={state.dismissNotice}>
          {state.notice}
        </Alert>
      )}
    </>
  )
}
```

```tsx
        submitLabel="Create"
        onSubmit={(name) => api.invoke('library:createDance', songId, name)}
```
